# 📦 Tracking Automation Pro

إضافة كروم احترافية لأتمتة إدخال أرقام تتبع الطرود — Manifest V3

---

## 🚀 تعليمات التثبيت

### الخطوة 1: إضافة مكتبة SheetJS (لاستيراد Excel)

```bash
# تنزيل المكتبة
curl -o libs/xlsx.full.min.js https://cdn.sheetjs.com/xlsx-0.20.1/package/dist/xlsx.full.min.js
```
أو من المتصفح: افتح الرابط أعلاه، Ctrl+S → احفظ داخل مجلد `libs/`

### الخطوة 2: تثبيت الإضافة في كروم

1. افتح المتصفح واذهب إلى: `chrome://extensions/`
2. فعّل **وضع المطور** (Developer Mode) من الزاوية العلوية اليمنى
3. اضغط **"تحميل غير مضغوط"** (Load unpacked)
4. اختر مجلد `tracking-automation-pro`
5. ✅ الإضافة جاهزة!

## 🎯 كيفية الاستخدام

### 1. إدخال أرقام التتبع
**لصق النص:**
```
yal-K99TVS yal-R86HTR yal-K43CHX
yal-B85KKK yal-N28SVT yal-T81VMK
```
أو رقم في كل سطر، أو مفصولة بفواصل — النظام يتعرف تلقائيًا.

**استيراد Excel:** اضغط زر "استيراد Excel" واختر ملف .xlsx أو .xls

### 2. الإعدادات
- **إرسال تلقائي:** يضغط Enter أو يرسل الفورم بعد كل إدخال
- **التأخير (ms):** الوقت بين كل إدخالين (الحد الأدنى 200ms)

### 3. التشغيل
1. اذهب للصفحة التي تحتوي على حقل `<input id="tracking">`
2. افتح الإضافة وأدخل الأرقام
3. اضغط **بدء** ← تبدأ الأتمتة!

## 🔧 استكشاف الأخطاء

**"غير متصل" في شريط الحالة:**
- تأكد من وجود حقل `<input id="tracking">` في الصفحة
- جرب تحديث الصفحة

**لا يعمل الإرسال التلقائي:**
- قد تحتاج للتعديل في content.js حسب بنية الموقع
- جرب تعطيل الإرسال التلقائي والإرسال يدويًا

**استيراد Excel لا يعمل:**
- تأكد من تثبيت مكتبة SheetJS (انظر الخطوة 1)

## ⌨️ تبويب الاختصارات (جديد في v1.1)

الإضافة الآن فيها تبويبان: **أرقام التتبع** (كما كان) و**الاختصارات**.

### إدارة الاختصارات
جدول: الاختصار | النص | id | تعديل / حذف. توجد اختصارات افتراضية يمكن تعديلها أو حذفها، وزر **استعادة الافتراضية** يرجعها.

### الاستخدام في أي موقع
1. **التوسيع الفوري:** اكتب الاختصار (مثل `/tr`) في أي خانة كتابة فيُستبدل بالنص المحفوظ. يعمل أيضًا في المحررات النصية (contenteditable)، ولا يعمل في حقول كلمات المرور.
2. **الاقتراح حسب id:** إذا كان لحقل الصفحة `id` مطابق لـ id الاختصار (مثل `tracking`) يظهر اقتراح عند التركيز على الحقل وهو فارغ، واضغط **Tab** للصق النص (Esc لإخفاء الاقتراح).

### ملاحظات
- لا يُسمح بمسافات في الاختصار، ولا بأن يكون اختصار بداية لاختصار آخر (مثل `/t` و`/tr`) لأن التوسيع فوري.
- يُشترط أن يسبق الاختصار بداية السطر أو مسافة، حتى لا يعمل داخل كلمة.
- لا يعمل التوسيع على الأرقام التي تحقنها أتمتة التتبع، فلا تداخل بين الميزتين.
- بعد تحديث الإضافة من `chrome://extensions` أعد تحميل الصفحات المفتوحة.
